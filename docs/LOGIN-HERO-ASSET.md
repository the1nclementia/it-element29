# Исходный asset для Login Hero

Текущий репозиторий не содержит подходящего изображения для левой части `/login`.

Нужен отдельный PNG или WebP, подготовленный из исходной 3D-композиции:

- соотношение сторон около 1.5:1 или широкий master без UI;
- крупные светлые металлические поверхности и мягкие отражения;
- оранжевое свечение только в стыках;
- без текста, логотипов, полей, кнопок, курсоров и элементов авторизации;
- sRGB, без внешних runtime-ссылок и шрифтов.

Файл следует положить как `frontend/public/brand/login-hero-background.webp`.
Frontend загружает его безопасно: до успешной загрузки показывается нейтральный
фон, после загрузки выполняется плавное появление и медленный световой sweep.

`frontend/public/brand/login-hero.png` не подходит: он содержит обрезанный текст
из макета и намеренно не используется.
