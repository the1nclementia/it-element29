- Каталог, справочники, совместимость, минимальный остаток, поступления, выдачи,

  создания, без предварительного просмотра. Исправляется существующая форма.
- Личные черновики `0004_inventory_drafts` уже написаны, но требуют завершения
  подключения и браузерной приёмки. Пользователь подтвердил хранение на сервере.
- Excel API реализован, необходимо подключить скачивание в UI и проверить его.
- Восстановление перепроектировано в `restore-new` на новый пустой контур;
  прежний destructive сценарий не запускается. Репетиция должна сравнить данные/фото.
- README/ARCHITECTURE/DATABASE/ROADMAP/PROGRESS устарели и описывали этап 2.
- PNG логотипов содержали непрозрачный фон RGB(247,246,244). Генеративная обработка
  изменила контуры и отклонена. По явному разрешению пользователя фон удалён
  локально из исходника, исходные файлы сохранены. Подключены отдельные RGBA PNG.

## Решения

- Существующий складской service остаётся единственным способом проведения.
  Черновик принадлежит оператору, не изменяет остаток до проведения, использует
  version и атомарную запись состояния вместе с документом. Оператор документа
  — ответственный за проведение; сотрудник — получатель, не учётная запись входа.
- Excel содержит фактический снимок запроса, текстовые ячейки не выполняют формул.
  Более 10 000 строк требуют уточнить фильтр; это явный отказ, а не усечение.
- Новые категории не создаются автоматически. Нормализация имён и проверки
  дубликатов выполняются сервером, в том числе при конкурентном создании.
- Предпросмотр файлов использует только локальные blob URL; CSP разрешает blob
  исключительно для img-src. Остальные ограничения сохраняются.
- Проверенная 20.10 локальная БД уже имеет `0004_inventory_drafts`; ревизии
  0001–0004 неизменяемы. Действующие данные/volumes и `.env` сохраняются.
- Приёмка ведётся в отдельном контуре, с синтетическими данными и runtime-ролью.
  Обновление локальной сборки — только после проверенной резервной копии.
