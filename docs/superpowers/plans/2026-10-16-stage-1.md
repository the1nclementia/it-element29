# Этап 1 — план реализации

**Goal:** запускаемый серверный каркас без реализации этапов 2–8.
**Architecture:** модульный монолит FastAPI, PostgreSQL, отдельный Alembic runner.
**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2, Alembic, Pydantic 2, pytest, Docker, Nginx.
**Spec:** ARCHITECTURE.md и DATABASE.md.
**Execution:** последовательно в текущей новой папке, без отдельного worktree.

## Ограничения

- Только этап 1; никаких бизнес-CRUD до серверной авторизации.
- PostgreSQL обязателен, SQLite не применяется даже как подмена интеграционного теста.
- Нет секретов и реальных данных в Git; оригинальные логотипы сохраняются без изменений.

## Контроль риска

- Отсутствующая БД: readiness 503, liveness 200, ответ без секретов.
- Отставшая миграция: readiness 503 даже при SELECT 1.
- Пароль с @/%: URL создаётся через SQLAlchemy URL, не строковую интерполяцию.
- Несогласованные справочники: FK/unique/check проверяются в PostgreSQL.
- Незафиксированная транзакция: изменения откатываются при закрытии сессии.
