# Этап 3 — план реализации

> Исполнение в текущем сеансе с executing-plans и dispatching-parallel-agents для
> независимых областей; общий контракт зафиксирован до реализации.

**Goal:** полностью работающий склад/выдача по заданию пользователя, сохранение этапа 2.
**Architecture:** API → service → SQLAlchemy → PostgreSQL, единый ledger, typed photo links.
**Tech Stack:** Python3.12+, PostgreSQL17, React/TS; новые зависимости только multipart/Pillow.
**Spec:** docs/STAGE-3-DESIGN.md и исходное полное задание пользователя от 18.10.2026.
