# Офлайн-выпуск и развёртывание — план реализации

> Исполнение в текущем сеансе по согласованному заданию; дополнительные агенты и коммиты в этой подзадаче не создаются. Общий коммит делает основной исполнитель.

**Цель:** переносить конкретный Git commit и версию с Windows на Ubuntu 24.04 без корпоративных облачных API.

**Архитектура:** buildx собирает Linux-образы из чистого committed snapshot; allowlist выпуска включает только образы, deploy-инструменты и документацию. Python standard library проверяет архивы, manifest и контрольные суммы, управляет Compose через argv без shell. Bash — точка входа. Раздельные owner/runtime роли; обновление останавливает запись и сохраняет проверенный backup до миграции. Восстановление — отдельная команда с вводимым подтверждением.

**Стек:** PowerShell 7, Python 3.12, Bash, Docker Engine/Buildx/Compose, PostgreSQL 17, Nginx TLS.

**Основание:** AGENTS.md, docs/STAGE-2-DESIGN.md, задание на офлайн-перенос. Только этап 2.

## Ограничения

- Не менять dev Compose, backend и frontend в этой подзадаче.
- Не включать секреты, реальные базы, uploads, исходный репозиторий в выпуск.
- Не развёртывать на корпоративном сервере; использовать только отдельный Docker-контур с синтетическими данными.
- Стабильные project/volumes/config вне каталога версии; runtime не использует owner.
- SHA256 обеспечивает целостность, происхождение подтверждается отдельным доверенным каналом.

## Фокус проверки

- Повреждённый архив, traversal, symlink и лишние файлы: отказ до извлечения/запуска Docker.
- Некорректная версия, manifest и env с shell-выражениями: отказ без исполнения содержимого.
- Ошибка backup: миграция не запускается; ошибка миграции: автоматического восстановления нет.
- Неверная версия backup и отсутствие подтверждения: разрушительных действий нет.
- Повторный deploy/изменение config/major PostgreSQL: отказ с сохранением текущих данных.

## Проверка 18.10.2026

46 pytest прошли на Windows и внутри Linux-контейнера. Репетиция на Docker Desktop (Linux amd64) выполнила save/load образов, первую миграцию, HTTPS readiness, update с согласованным pg_dump/files backup, явный restore и сравнение восстановленных синтетических данных БД/файла. Тестовые контейнеры и volumes удалены. Проверка выявила и устранила отказ Compose `run --no-deps` до создания external volumes: Nginx preflight выполняется отдельным `docker run --network none`. Также защищены неизменность выпуска от Python bytecode, pending marker при сбое PostgreSQL update и отсутствие бинарного downgrade PostgreSQL при restore/restart. Проверка имён runtime-роли согласована с backend (3–63 символа, запрет системных ролей) до любого обращения к Docker; шесть регрессионных случаев прошли RED→GREEN.

Ограничения: Windows adapter не заменяет Ubuntu root/permissions/flock/systemd/firewall/DNS/corporate-TLS приёмку. Корпоративный сервер не изменялся. Официальный versioned archive собирается из чистого commit после общего коммита; тестовый snapshot репетиции не объявляется релизом.
