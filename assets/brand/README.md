# Оригинальные фирменные ресурсы

Три PNG из вложений пользователя скопированы без изменений:

- mark-original.png — знак [29].
- wordmark-original.png — название компании.
- wordmark-tagline-original.png — название и подпись.

Этап 1 использует оригинальный знак как favicon и название на технической странице.
Боковая панель, авторизация и «О системе» появятся на этапе 2.
